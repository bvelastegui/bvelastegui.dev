# Portfolio Personal

Sitio web personal desarrollado con Astro 6 como generador de sitios estáticos y Tailwind CSS v4 para los estilos.

## Características

- Generación estática (SSG) con Astro 6
- Content Collections con el nuevo loader API
- Secciones de About, Experience, Education, Projects y Contact
- Diseño responsive con Tailwind CSS v4
- Desplegado en GitHub Pages vía GitHub Actions

## Tecnologías

- Astro 6 con output estático
- Tailwind CSS v4 + @tailwindcss/typography
- TypeScript para type safety
- pnpm como package manager
